# 公开发布说明

整理日期：2026-10-19。范围：复赛 B 榜用户反馈最高的 V372（75.1101）。

## 与原始归档的关系

公开版从本地训练、推理、导出和审计源码中按导入关系收集依赖。对于原 V372 生产审计绑定的 28 个项目源码文件，先验证原 SHA-256，再生成公开副本。

涉及专用 Linux 服务器根目录的表达式，在公开副本中统一改为 `Path.home() / 'csig'`。原始源码未被修改；公开版改写文件及前后 SHA-256 记录在 `configs/source_provenance.json`。
这是目录隐私清理，不改变采样、融合、评分或模型结构；但源码和路径身份发生变化会影响原先冻结的来源校验。
不声称公开副本与历史运行逐字节一致，也不声称只克隆仓库就能得到相同线上分数。
对应的 CLI 测试改为根据模块根目录对比合同文件路径，避免把专用服务器目录写入测试；其余测试逻辑保持原样。

第三方代码不随仓库分发。`configs/source_provenance.json` 中第三方文件的相对路径和 SHA-256 仅用于标识当时环境。
没有打包源码内部使用的完整原生产报告，因为它包含服务器目录、测试物体索引和大量内部来源信息；公开证据采用明确标注的摘要。

## 成绩与验证的区别

`results/leaderboard_history.json` 中的成绩均来自用户反馈，尚未在本次发布中独立核验。A/B 榜不是同一测试集，不混用分数。

`results/v372_audit_summary.json` 汇总原文件与数值审计的事实，不包含测试标签或逐样本预测。
ZIP 结构正确、来源哈希一致、合成测试通过，都不能代替盲测效果评估。

本次运行的检查结果会保存到 `docs/VERIFICATION.json`。只有实际运行的测试才会被标为通过。
